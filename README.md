# Simple Calculator

A Python CLI calculator application supporting basic arithmetic operations with input validation and error handling.

## Features
- **Operations Supported**:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`) with division-by-zero protection
- **Input Validation**: Safely handles non-numeric inputs and invalid menu choices.
- **Continuous Execution**: Option to perform multiple calculations or exit cleanly.

## How to Run

1. Open your terminal in this directory.
2. Run:
   ```bash
   python calculator.py
   ```

## Running Tests

To run the automated unit tests:
```bash
python -m unittest test_calculator.py
```
